# Open-Source Session Notes — [8/9/2026]

## Summary
- this session talks about what is the Open-Source, why we need it, and how we can contribute to Open Source Projects.

## Discussion Notes
### What is Open source
- Key points:
  - **Free** and Public Software.
  - **Large** Code-bases.
  - **Production** Software. 
- Decisions:
  - Open Source Software is code that has been published publicly; it's **Free** most of the time.
  - Some programs that influence our lives are open source, and they have **Large** code bases. These code bases have been developed by thousands of people who contribute to the source code of these programs.
  - The contribution of anyone who contributes to open source projects goes to the **Production** level at the end of the process.
### Why should I contribute to Open Source Projects
- Key points:
  - **Real-World** CV leverage
  - Navigation throw **Massive** Code Bases 
  - **Professional** Workflow
  - Building Global **Network** 
- Decisions:
  - Contributing to open-source projects gives your CV more leverage than others because you solve **real-world** problems.
  - Contributing to open-source projects gives you unique experience navigating **massive** codebases that you can't get in average workflows at traditional Companies, and it helps you read any Codebase More easily. 
  - Contributing to open-source projects will give you a chance to work in a **Professional** Workflow that has a strict process for making contributions, beginning from opening an issue to merging your contribution into the main branch of the project.
  - Contributing to an open-source project will give you a way to build a global **network** by working and collaborating with experienced people from different technical backgrounds.
  - Contributing to an open-source project will open up a chance for you to work **full-time** with the companies that own the project you contribute to.

### Open Source Programs

- Key points:
  - Google Summer Of Code (GSoC)
  - Linux Foundation (LFX)
- Decisions:
  - Google Summer Of Code (GSoC):
    - GSoC is a program that forced on brining new contributers into open source software world.
    -  GSoC's organizations offers experienced mentors guidance.
    - GSoC always need general awareness of the source code of the project you want to work in.
    - Historically, GSoC open for contributor proposals open in March.
  - Linux Foundation (LFX):
    - LFX is globally, fully remote program providing structure and paid mentor-ship.
    - The difference between LFX and GSoC is that LFX has 3 terms per year; (Spring, Summer, Fall).
